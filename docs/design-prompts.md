# Prompt สำหรับ Claude Design: TableTime

วิธีใช้:

1. เริ่มโปรเจกต์ใหม่ใน Claude Design แล้ววาง **Prompt 1** ทั้งก้อน
2. ตรวจ design system (สี ฟอนต์ component) ให้พอใจก่อน ถ้าต้องแก้ ให้แก้ในรอบนี้ เพราะทุกหน้าหลังจากนี้จะใช้ตาม
3. วาง Prompt 2 ถึง 8 ทีละอัน ในโปรเจกต์เดียวกัน
4. เสร็จแล้วใช้ **Handoff to Claude Code** เก็บลิงก์และ screenshot ทุกหน้าไว้ที่ `design/`

ข้อความบนหน้าจอเป็นภาษาไทยทั้งหมด ยกเว้นป้าย Highest rated!, Most reviewed!, Limited Seats Left! และชื่อแอป

## Prompt 1: Design system + รายการร้าน + รายละเอียดร้าน

```
ออกแบบเว็บแอปชื่อ "TableTime" แอปจองโต๊ะร้านอาหาร และ community รีวิวร้าน
ภาษาไทยทั้งหมด ออกแบบสำหรับเดสก์ท็อปก่อน (1440px) แต่ต้องใช้งานบนมือถือได้ (390px) light mode อย่างเดียว

## แนวคิดของแอป
- หนึ่งบัญชีมีสองบทบาท: ร้านของตัวเองเราเป็น "เจ้าของร้าน" ร้านของคนอื่นเราเป็น "ลูกค้าและผู้รีวิว"
- มีสวิตช์โหมดแบบ Airbnb ("สลับเป็นเจ้าของร้าน" / "สลับเป็นลูกค้า") แต่ละโหมดมีเมนูของตัวเอง
- ความรู้สึก: แอปจองร้านอาหารทันสมัย สีสดน่ากิน แบบ Wongnai / OpenTable ใช้ง่าย อ่านง่าย

## Design system (สร้างเป็นหน้าแรกของโปรเจกต์)
- สีหลัก: ส้มแดง (โทน Wongnai) ใช้กับปุ่มหลัก ลิงก์ และแท็บที่เลือก
- สีสถานะ ต้องแยกจากสีหลักให้ชัดเจน ห้ามกลืนกัน และคอนทราสต์ผ่าน WCAG AA:
  - อำพันหรือเหลือง = Limited Seats Left! / ใกล้เต็ม
  - แดง = เต็ม, error, การกระทำอันตราย (ลบ, ยกเลิก) ต้องต่างจากสีส้มแดงหลักอย่างเห็นได้ชัด
  - เขียว = จองสำเร็จ, ว่าง
  - เทา = ยกเลิกแล้ว, ปิด, ปุ่มที่กดไม่ได้
- ดาวรีวิวใช้สีทองหรืออำพัน
- ฟอนต์: Prompt (Google Fonts) ทั้งหัวข้อและเนื้อหา ตัวเลขเวลาและราคาต้องอ่านชัด
- ออกแบบให้สร้างด้วย Tailwind CSS v4 + shadcn/ui + ไอคอน lucide ได้ตรง ๆ
  (Button, Badge, Card, Tabs, Dialog, Select, Input, Textarea, DropdownMenu, Avatar, Tooltip, Skeleton)
- แสดง token ของสี ระยะห่าง radius และ shadow พร้อมตัวอย่าง component ทุกสถานะ (ปกติ, hover, disabled, error)

## Navbar (ใช้ทุกหน้า)
3 แบบ:
1. ยังไม่ login: โลโก้ TableTime · "ร้านทั้งหมด" · ปุ่ม "เข้าสู่ระบบ" (ไม่มีสวิตช์โหมด)
2. โหมดลูกค้า: โลโก้ · ร้านทั้งหมด · การจองของฉัน · รีวิวของฉัน · ปุ่ม "สลับเป็นเจ้าของร้าน" · avatar
3. โหมดเจ้าของร้าน: โลโก้ + ป้าย "เจ้าของร้าน" · ภาพรวม · ร้านของฉัน · การจองของร้าน · รีวิวของร้าน · ปุ่ม "สลับเป็นลูกค้า" · avatar
   ให้โหมดเจ้าของร้านดูต่างจากโหมดลูกค้าพอสมควร (เช่น navbar สีเข้ม) แต่ยังเป็นแบรนด์เดียวกัน
เมนู avatar: โปรไฟล์ของฉัน · ออกจากระบบ

## หน้า 1: รายการร้าน (หน้าแรกของโหมดลูกค้า)
- ช่องค้นหาชื่อร้าน + ตัวกรองประเภทอาหาร (ไทย, ญี่ปุ่น, อีสาน, คาเฟ่, ปิ้งย่าง, ...)
- แท็บ "Highest rated!" / "Most reviewed!"
- การ์ดร้าน: รูป, ชื่อ, ประเภทอาหาร, ★ 4.8, "126 รีวิว", "10 ที่นั่ง", สถานะวันนี้ ("เปิดอยู่ · ปิด 22:00" / "ปิดวันนี้")
- ร้านที่มีรีวิวน้อยกว่า 3 แสดงคะแนนพร้อมคำว่า "รีวิวยังน้อย" และอยู่ท้ายรายการในแท็บ Highest rated!
- ร้านของผู้ใช้เองติดป้าย "ร้านของคุณ"
- pagination ด้านล่าง
ข้อมูลตัวอย่าง: ครัวริมคลอง ★4.8 126 รีวิว 10 ที่นั่ง / ส้มตำหน้าตลาด ★4.6 311 รีวิว 24 ที่นั่ง /
ก๋วยเตี๋ยวเรือหน้าวัด ★4.3 58 รีวิว 16 ที่นั่ง / ร้านใหม่ ★5.0 2 รีวิว (รีวิวยังน้อย)

## หน้า 2: รายละเอียดร้าน
- แกลเลอรีรูป (รูปใหญ่ 1 + รูปเล็ก แสดง "+5 รูป")
- ชื่อร้าน, ประเภทอาหาร, รายละเอียด, จำนวนที่นั่ง, ยกเลิกได้ล่วงหน้า X นาที
- ตารางเวลาเปิด 7 วัน: "จันทร์ ปิด", "อังคาร 18:00–02:00 (ข้ามเที่ยงคืน)", "เสาร์ เปิด 24 ชม." ไฮไลต์วันนี้
- กล่องจอง (ติดขวา บนเดสก์ท็อป):
  - จำนวนคน (stepper), วันที่ (date picker ไม่เกิน 60 วัน), เวลาเริ่มและเวลาสิ้นสุด (dropdown ช่องละ 30 นาที)
  - dropdown แสดงเวลาต่อเนื่องสำหรับร้านข้ามเที่ยงคืน เช่น "00:30 (วันถัดไป)"
  - ใต้ฟอร์มมี "กราฟที่นั่ง": กราฟแท่งแนวนอนตามเวลา 1 แท่งต่อ 30 นาที ความสูง = ที่นั่งที่ถูกจอง
    มีเส้นประแสดงจำนวนที่นั่งทั้งหมด ไฮไลต์ช่วงที่ผู้ใช้เลือกไว้ และแสดงส่วนที่จะเพิ่มขึ้นถ้าจอง
    ช่องที่เหลือ ≤ 3 ที่เป็นสีอำพันพร้อมป้าย "Limited Seats Left!" ช่องที่เต็มเป็นสีแดง
    (แรงบันดาลใจ: กราฟแท่งแบบ stacked บน timeline ร้าน 10 ที่ ช่วง 12:00–13:00)
  - ข้อความเล็ก: "จองได้ขั้นต่ำ 1 ชั่วโมง"
  - ปุ่ม "จองเลย"
  - แสดงสถานะ error ภาษาคนใต้ปุ่ม เช่น "ช่วง 12:30–13:00 เหลือที่นั่ง 3 ที่ ลองลดจำนวนคนหรือเลือกเวลาอื่น"
- ส่วนรีวิว:
  - สรุป: ★ 4.3 ตัวใหญ่, "58 รีวิว", แท่งจำนวนรีวิวของ 5★ ถึง 1★
  - ฟอร์มรีวิว: เลือกดาว 1–5 + ข้อความ + ปุ่ม "ส่งรีวิว"
  - ถ้ารีวิวไปแล้ว: การ์ด "รีวิวของคุณ" มีปุ่มแก้ไขและลบ แทนฟอร์ม
  - รายการรีวิว ใหม่สุดก่อน: avatar, ชื่อ (กดไปโปรไฟล์ได้), ดาว, วันที่, ข้อความ
    และถ้าร้านตอบ แสดงกล่อง "ตอบกลับจากร้าน" ซ้อนอยู่ใต้รีวิว
- ออกแบบหน้านี้ 3 สถานะ:
  (ก) ยังไม่ login: กดจองหรือรีวิวแล้วขึ้น "เข้าสู่ระบบเพื่อจอง"
  (ข) ลูกค้า login แล้ว
  (ค) เจ้าของร้านดูร้านตัวเองในโหมดลูกค้า: แถบด้านบน "นี่คือร้านของคุณ · จัดการในโหมดเจ้าของร้าน →"
      ฟอร์มจองยังใช้ได้ แต่ที่ฟอร์มรีวิวแสดงข้อความ "รีวิวร้านของตัวเองไม่ได้" แทน
```

## Prompt 2: ใบจอง + การจองของฉัน

```
ใช้ design system และ navbar โหมดลูกค้าเดิมของ TableTime

## หน้า: จองสำเร็จ (ใบจอง)
- การ์ดแบบตั๋ว (ขอบหยักหรือเส้นประแบ่งครึ่ง) หัวการ์ด "ใบจอง" + เลขจอง "#0711"
- ชื่อร้าน, วันที่ "11 ต.ค.", เวลา "12:00–13:00", จำนวน "7 คน", "ยกเลิกได้ถึง 11:30"
- ถ้าช่วงนั้นเหลือที่นั่งน้อย แสดงป้าย "Limited Seats Left! เหลือ 3 ที่นั่ง"
- ไอคอนหรือแถบสีเขียว "จองสำเร็จ"
- ปุ่ม: "ดูการจองของฉัน", "กลับไปหน้าร้าน"

## หน้า: การจองของฉัน
- แท็บ: กำลังจะมาถึง / ที่ผ่านมา / ยกเลิกแล้ว (มีตัวเลขจำนวนบนแท็บ)
- แต่ละรายการ: รูปร้านเล็ก, ชื่อร้าน, วันเวลา, จำนวนคน, สถานะ, "แก้ไขหรือยกเลิกได้ถึง 11:30"
- ปุ่ม "แก้ไข" และ "ยกเลิกการจอง"
  ถ้าเลยเวลาแล้ว ปุ่มเป็นสีเทาพร้อม tooltip "เลยเวลาที่แก้ไขหรือยกเลิกได้แล้ว (11:30)"
- Dialog แก้ไข: ฟอร์มเดียวกับกล่องจอง (จำนวนคน, วันที่, เวลาเริ่ม–สิ้นสุด + กราฟที่นั่ง)
- Dialog ยืนยันยกเลิก: "ยกเลิกการจองที่ครัวริมคลอง 11 ต.ค. 12:00–13:00 ใช่ไหม" ปุ่มยกเลิกเป็นสีแดง
- Empty state: "ยังไม่มีการจอง" + ปุ่ม "ดูร้านทั้งหมด"
```

## Prompt 3: รีวิวของฉัน + โปรไฟล์ผู้รีวิว

```
ใช้ design system และ navbar โหมดลูกค้าเดิมของ TableTime

## หน้า: รีวิวของฉัน
- รายการรีวิวทุกร้านที่ฉันเขียน: รูปร้านเล็ก + ชื่อร้าน (กดไปหน้าร้านได้), ดาว, วันที่, ข้อความ
- ปุ่มแก้ไข (inline edit ดาว + ข้อความ) และลบ (dialog ยืนยัน)
- ถ้าร้านตอบกลับแล้ว แสดงคำตอบของร้านใต้รีวิว
- Empty state: "ยังไม่ได้รีวิวร้านไหน" + ปุ่ม "ดูร้านทั้งหมด"

## หน้า: โปรไฟล์ผู้รีวิว (public ใครก็ดูได้)
- avatar ใหญ่, ชื่อ, "เป็นสมาชิกตั้งแต่ ก.ย. 2026", สถิติ: จำนวนรีวิว, คะแนนเฉลี่ยที่ให้
- รายการรีวิวทั้งหมดของคนนี้ (แบบเดียวกับหน้ารีวิวของฉัน แต่ไม่มีปุ่มแก้ไข)
- ถ้าเป็นโปรไฟล์ของตัวเอง แสดงลิงก์ "จัดการรีวิวของฉัน"
```

## Prompt 4: โหมดเจ้าของร้าน: ร้านของฉัน + ฟอร์มร้าน

```
ใช้ design system ของ TableTime และ navbar แบบ "โหมดเจ้าของร้าน"

## หน้า: ร้านของฉัน
- การ์ดร้านแต่ละร้าน: รูป, ชื่อ, ★ คะแนน + จำนวนรีวิว, ที่นั่ง, การจองวันนี้ X รายการ
  ปุ่ม "จัดการ" และ "ดูหน้าร้าน" (เปิดหน้าร้านในโหมดลูกค้า)
- ปุ่ม "+ สร้างร้านใหม่"
- Empty state (ยังไม่มีร้าน): ภาพประกอบ + "เปิดร้านแรกของคุณ" + ปุ่มสร้างร้าน

## หน้า: สร้างและแก้ไขร้าน (ฟอร์มยาว แบ่งเป็น section)
1. ข้อมูลร้าน: ชื่อ, ประเภทอาหาร (select), รายละเอียด (textarea)
2. รูปร้าน: กรอก URL รูปได้หลายรูป (อย่างน้อย 1) แสดง preview เรียงลำดับได้ ลบได้
   ถ้าไม่มีรูปแสดง error "ต้องมีรูปอย่างน้อย 1 รูป"
3. จำนวนที่นั่ง: ตัวเลข พร้อมคำอธิบาย "นับเป็นที่นั่ง ร้าน 10 ที่ = รับพร้อมกันได้ 10 คน"
4. เวลาเปิด–ปิด: 7 แถว (อาทิตย์ถึงเสาร์) แต่ละแถวเลือกได้ 3 แบบด้วย segmented control:
   "ปิด" / "เปิด 24 ชม." / "กำหนดเวลา" (แสดงช่องเวลาเปิดและปิด)
   ถ้าเวลาปิดน้อยกว่าเวลาเปิด แสดงป้ายเล็ก "ปิดวันถัดไป" ถ้าเวลาปิดเท่ากับเวลาเปิดแสดง error
   มีปุ่ม "ใช้เวลาเดียวกันทุกวัน"
5. การยกเลิก: "ลูกค้ายกเลิกหรือแก้ไขได้ล่วงหน้าอย่างน้อย" [30] นาที (ขั้นต่ำ 30)
- ปุ่ม "บันทึก" ติดด้านล่าง, error แสดงใต้ช่องที่ผิดเป็นภาษาคน
- ในโหมดแก้ไข มี "โซนอันตราย" ท้ายฟอร์ม: ปุ่มลบร้าน (สีแดง)
  - dialog ยืนยันลบ
  - ถ้ายังมีการจองในอนาคต: แสดงกล่องแจ้ง "ลบร้านไม่ได้ เพราะยังมีการจองที่ยังไม่ถึงเวลา 4 รายการ"
```

## Prompt 5: โหมดเจ้าของร้าน: หน้าจัดการร้าน (แท็บ)

```
ใช้ design system ของ TableTime และ navbar โหมดเจ้าของร้าน

## หน้า: จัดการร้าน (เช่น "ครัวริมคลอง")
หัวหน้า: รูปเล็ก + ชื่อร้าน + ★ + ปุ่ม "ดูหน้าร้าน"
แท็บ: ข้อมูลร้าน / การจอง / รีวิว / วันหยุด

### แท็บ ข้อมูลร้าน
ใช้ฟอร์มร้านจาก prompt ก่อนหน้า

### แท็บ การจอง
- ตัวเลือกวันที่ (ปุ่ม < วันนี้ >)
- กราฟที่นั่งรายช่อง 30 นาทีของวันนั้น (component เดียวกับหน้าร้าน) แท่งแต่ละแท่งแยกสีตามการจอง
  hover แล้วแสดงว่าใครจองกี่คน
- ตารางการจอง: เวลา, ชื่อลูกค้า, จำนวนคน, สถานะ (active / ยกเลิกแล้ว), วันที่จอง
- สรุปด้านบน: การจองวันนี้ X รายการ, ลูกค้ารวม Y คน, ช่วงที่แน่นที่สุด

### แท็บ รีวิว
- สรุปคะแนน + แท่ง 5★ ถึง 1★
- ตัวกรอง: ทั้งหมด / ยังไม่ได้ตอบ
- แต่ละรีวิว: ผู้รีวิว, ดาว, ข้อความ, ปุ่ม "ตอบกลับ" (textarea แบบ inline)
- ถ้าตอบแล้ว: แสดงคำตอบ + ปุ่มแก้ไขหรือลบคำตอบ
- ถ้ารีวิวถูกแก้หลังร้านตอบ: ป้ายเล็ก "รีวิวถูกแก้ไขหลังร้านตอบ"

### แท็บ วันหยุด
- สรุปวันหยุดประจำสัปดาห์ (อ่านจากเวลาเปิด–ปิด) + ลิงก์ไปแก้
- ปฏิทินเลือกวันหยุดเฉพาะวัน + หมายเหตุ (เช่น "หยุดสงกรานต์")
- รายการวันหยุดที่ตั้งไว้ ลบได้
- Dialog ยืนยัน (ไม่ใช่ error ใช้สีอำพันหรือข้อมูล ไม่ใช้สีแดง):
  "วันที่ 13 เม.ย. มีการจองอยู่ 3 รายการ การจองเหล่านี้จะยังอยู่ ลูกค้าจองใหม่ในวันนี้ไม่ได้ ยืนยันตั้งเป็นวันหยุดไหม"
  แสดงรายการการจองที่ทับ ปุ่ม "ยืนยัน" และ "ยกเลิก"
```

## Prompt 6: โหมดเจ้าของร้าน: ภาพรวม + การจองของร้าน + รีวิวของร้าน (รวมทุกร้าน)

```
ใช้ design system ของ TableTime และ navbar โหมดเจ้าของร้าน

## หน้า: ภาพรวม (dashboard)
- การ์ดสถิติ: การจองวันนี้, ลูกค้าวันนี้, คะแนนเฉลี่ยรวม, รีวิวที่ยังไม่ได้ตอบ
- การ์ดของแต่ละร้าน (ย่อ): ชื่อ, ★, การจองวันนี้, ป้าย "ใกล้เต็ม" ถ้ามีช่วงที่เหลือ ≤ 3 ที่
- "การจองที่กำลังจะมาถึงวันนี้" (5 รายการล่าสุด)
- "รีวิวล่าสุดที่ยังไม่ได้ตอบ" (3 รายการ) พร้อมปุ่มตอบ

## หน้า: การจองของร้าน (ทุกร้าน)
- ตัวกรองร้าน (ทุกร้าน / เลือกร้าน) + ตัวเลือกวันที่
- ตารางเหมือนแท็บการจอง แต่มีคอลัมน์ชื่อร้าน

## หน้า: รีวิวของร้าน (ทุกร้าน)
- ตัวกรองร้าน + ทั้งหมด / ยังไม่ได้ตอบ
- รายการรีวิวเหมือนแท็บรีวิว แต่มีชื่อร้านกำกับ
```

## Prompt 7: สถานะร่วม

```
ใช้ design system ของ TableTime ออกแบบสถานะร่วมที่ใช้ได้ทุกหน้า:

1. Toast แจ้งผล: สำเร็จ (เขียว), ข้อผิดพลาด (แดง), ข้อมูล (น้ำเงินหรือเทา)
2. กล่อง error ในหน้า (inline alert) สำหรับ error จากเซิร์ฟเวอร์ ข้อความต้องเป็นภาษาคน เช่น
   - "ช่วง 12:30–13:00 เหลือที่นั่ง 3 ที่ ลองลดจำนวนคนหรือเลือกเวลาอื่น"
   - "ร้านไม่เปิดในช่วงเวลานี้"
   - "เวลานี้ผ่านไปแล้ว กรุณาเลือกเวลาใหม่"
   - "เลยเวลาที่แก้ไขหรือยกเลิกได้แล้ว (11:30)"
   - error ทั่วไป: "เกิดข้อผิดพลาด ลองใหม่อีกครั้ง" + ปุ่มลองใหม่
   ห้ามแสดงรหัส error หรือข้อความภาษาโปรแกรม
3. error ใต้ช่องฟอร์ม
4. Empty states: ไม่พบร้านที่ค้นหา, ยังไม่มีการจอง, ยังไม่มีรีวิว, ยังไม่มีร้าน
5. Loading: skeleton ของการ์ดร้าน, หน้าร้าน, ตาราง
6. หน้า 404 "ไม่พบหน้านี้" และหน้า "ต้องเข้าสู่ระบบก่อน"
7. Dialog ยืนยัน 2 แบบ: อันตราย (แดง: ลบ, ยกเลิก) และแจ้งให้ทราบ (อำพัน: วันหยุดทับการจอง)
```
